## 🔴 P0 — CRITICAL PATH (must do first)

### SCHEDULER-001: Durable Scheduler (NDJSON + Crash Recovery)
***Status:** ✅ **Verified** (v0.5.0)  
**Priority:** P0 — This is the #1 bottleneck. Everything else depends on it.

**What it is:** Replace the fragile JSON scheduler with CortexLLM's event-sourced NDJSON pattern.

**Includes (merges 4 overlapping items):**
- Scheduler durability (NDJSON + crash recovery)
- CortexLLM file persistence for scheduler
- Scheduler reconciliation on restart
- Migration from JSON to NDJSON

**Files to create:**
- `lib/scheduler/__init__.py`
- `lib/scheduler/store.py` — NDJSON event store (create, get, list, update, pause, resume, run_now, cancel, archive, clear_test_tasks, reconcile)
- `lib/scheduler/recovery.py` — Crash recovery, event replay, snapshot validation

**Files to modify:**
- `lib/overseer.py` — Replace `schedule_add/list/remove` with `scheduler.Store` calls

**Schema:**
```
~/.cortexagent/scheduler/
  tasks.json          ← canonical snapshot (atomic replace via tmp+rename)
  tasks.events.jsonl  ← immutable event log (append-only NDJSON)
  executions.jsonl    ← execution receipts (append-only NDJSON)
  state.json          ← cursor/checkpoint (generation number, schema version)
  lock                ← POSIX single-instance lock
```

**Events (NDJSON):**
```json
{"type":"create","id":"uuid","title":"...","state":"scheduled","next_run":"...","version":1}
{"type":"update","id":"uuid","state":"running","version":2}
{"type":"fire","id":"uuid","execution_id":"uuid","version":3}
{"type":"complete","id":"uuid","status":"success","version":4}
{"type":"cancel","id":"uuid","version":5}
{"type":"pause","id":"uuid","version":6}
{"type":"resume","id":"uuid","next_run":"...","version":7}
```

**Migration plan:**
1. Read `~/.cortexagent/overseer_schedule.json`
2. Validate schema
3. Generate NDJSON events from historical data
4. Write to `tasks.events.jsonl` + `tasks.json` (atomic)
5. Verify integrity (event count matches, read-back matches)
6. Switch overseer to new files
7. Keep old JSON for 24h grace period, then delete

**Acceptance criteria:**
- [ ] `tasks.json` is atomically replaced after each mutation
- [ ] `tasks.events.jsonl` captures every mutation (immutable, append-only)
- [ ] Crash recovery works: interrupt write mid-mutation, recover valid state
- [ ] Restart: tasks survive, next_run recalculated correctly
- [ ] One-shot task follows missed-run policy after downtime
- [ ] Recurring task computes next_run correctly after downtime
- [ ] All existing tasks migrated from JSON → NDJSON without data loss

**Includes (merges 2 items):**

- Backpressure metrics in UI

**Files to modify:**
- `lib/overseer.py` — Add `WorkerPool` class, integrate heartbeat into tick loop

**Design:**
```python
class WorkerPool:
    max_workers: int = 5
    heartbeat_interval: int = 60
    workers: List[Dict] = []  # {thread, last_heartbeat, status, current_task}
    
    def heartbeat_check() → None     # Replace dead workers
    def execute_task(task: Dict) → None  # Each worker calls this
    def record_backpressure(depth: int) → None  # Feed to metrics
```

**Acceptance criteria:**
- [ ] Worker pool starts N threads, each pulls from bounded queue
- [ ] Heartbeat checked every 60s in tick loop
- [ ] Dead worker (missed 2 heartbeats) detected and replaced
- [ ] Backpressure metrics: qsize, put_rate, get_rate, p95/p99 latency
- [ ] Metrics visible in `overseer status` and WebUI

### OBS-005: Auto-Capture Observability Spans
***Status:** ✅ **Verified** (v0.5.0)  
**Priority:** P2 (can run in parallel with SCHEDULER-001)

**What it is:** Wire the existing `observability.py` module into the live agent loop.

**Includes (1 item):**
- Auto-capture spans in react_loop, grammar_proxy, overseer

**Files to modify:**
- `lib/react_loop.py` — Wrap LLM calls, tool calls, beautify in `with Span(...)`
- `lib/grammar_proxy.py` — Wrap minify + grammar checks in spans
- `lib/overseer.py` — Wrap scheduler ops, queue dispatch in spans

**Pattern:**
```python
from lib.observability import trace, span

with trace("agent_run", user_input=prompt) as tr:
    with span(tr.id, "classify", "intent_classification") as s:
        intent = classify_intent(prompt)
    with span(tr.id, "framing", "prompt_framing") as s:
        framed = frame_prompt(prompt, intent)
    with span(tr.id, "llm", "tiny_model_query") as s:
        result = tiny_llm(framed)
        s.set_metric("tokens_in", len(prompt) // 4)
        s.set_metric("tokens_out", len(result) // 4)
        s.set_metric("latency_ms", (time.time() - start) * 1000)
    with span(tr.id, "beautify", "output_formatting") as s:
        output = beautify(result)
```

**Acceptance criteria:**
- [ ] Every LLM call produces a span with tokens_in, tokens_out, latency_ms
- [ ] Every tool call produces a span
- [ ] Every beautify/post-process produces a span
- [ ] Spans written to `~/.cortexagent/observability/traces.ndjson`
- [ ] `observability.py metrics` shows live metrics from spans
