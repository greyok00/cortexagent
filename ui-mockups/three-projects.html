Hard rules (per spec)

  • No project is named "CortexAgent" — that's a separate real project.
  • Tray popup = Tk, NOT a web console. Only action: Focus Brave.
  • Cross-status pills in popup are read-only — they never open other projects.
  • No cross-project navigation. Each project's mockups stay in their own folder.
  • Mockups are review material, not implementations. Real code is untouched.
  • Localhost-only bindings: 9999 (OSINT), 8093 (Security). 9999 ≠ 8093.
