  1. Why a 5-stage diagram. The pipeline is fast (≈2s) and rarely the cause of a bad answer; the cause is usually a bad retrieval or a bad compression. Showing the stages lets an operator see which one failed.
  2. Latency budget. Tokenize ≈ 4 ms · SlimToken ≈ 12 ms · Retrieve ≈ 28 ms · Generate ≈ 1.8 s · Type ≈ 8 ms.
  3. Why not a token-by-token animation. That hides the structure; this version exposes it. Animation should be reserved for a future "live mode" tab.
