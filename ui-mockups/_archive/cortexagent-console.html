Console anatomy · 6 regions · 5 tabs + Settings

  • titlebar — Tauri chrome + theme pill (click to open Settings) + window controls
  • status bar (top) — 6 live pills across surfaces: model, pipeline, sec, siem, soar, cases
  • sidebar — Surface nav only (Security / SOAR / Agent / OSINT / Cases). No raw URL list.
  • main — One tab per surface, each carrying useful features (NOT just stats)
  • terminal — Real embedded xterm.js running bash; pinned at bottom
  • statusbar (bottom) — current theme + history + clock

Theme picker: click the theme pill in the titlebar (or the gear icon) → Settings modal opens with all 9 themes. Picking one re-skins the entire window (chrome, sidebar, main, terminal, status bars) — not just one pane. Persistent in localStorage.
