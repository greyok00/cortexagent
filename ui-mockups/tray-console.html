Tray popup → full console flow

  • This popup is the collapsed tray window. 720×480, lives next to the tray icon. Shows the 9-check strip + an attention callout + 3 most-recent SOAR runs. That's the entire "do I need to act?" question in one frame.
  • "Open full console →" opens cortexagent-console.html (1320×820 Tauri-window mockup) — full console with sidebar nav across Security/Agent/OSINT/Cases, live status bar across surfaces, embedded xterm.js terminal at the bottom.
  • From the tray menu the item "◆ Open full CortexAgent console" (⌘⇧A) does the same. The "3 hardening failures · open console" item (⌘⇧H) also opens the console and lands on the Security tab.
  • In production this becomes: tray icon → right-click menu (Tk popup like sec_tray.py) → click opens the Tauri WebviewWindow at 1320×820 with the same layout. The Tauri app keeps a tray icon for the always-visible collapsed state.
  • Pattern reuse: the existing sec_tray.py 372-line Tk popup stays as the tray collapsed view (with its severity-color padlock). The Tauri app is the expanded view. Both share the same data sources (SIEM db, big-model status, etc.).
  • No auth in either view: localhost-only; webui bound to 127.0.0.1, never 0.0.0.0 (per the localhost-only binding rule).
